# Sea Radar

Локальний вебзастосунок для показу суден у Дуврській протоці на заняттях. Завдання: `docs/tasks/PROJECT_BRIEF.md` і файли спринтів у `docs/tasks/` — читай їх, а не переказ.

Настанови Next.js для агентів (файл генерує `next dev`): @AGENTS.md

## Стан
- R1–R3 (B-01…B-17) завершені й прийняті: `docs/checkpoints/CHECKPOINT-01.md`…`CHECKPOINT-05.md`, приймання R3 — `docs/reviews/ACCEPTANCE-R3.md`. Інструкція для викладача — `README.md`.
- Наступний етап — тільки за окремим change request у `docs/tasks/`. Поки його немає, нових функцій не додавати й вимог не вигадувати.

## Стек (версії зафіксовані точно)
- Node.js 24
- TypeScript 6.0.3, `strict: true` (не 7.x — latest у npm зараз 7, але стек вимагає 6.x)
- Next.js 16.4.2 (App Router) + React 19.3.1
- Leaflet 1.9.x — тільки на клієнті, шар OpenStreetMap Standard
- Playwright Test — єдиний тестовий раннер: проєкт `node` (перетворювач і збирач, без браузера) і `chromium` (інтерфейс)

Нові залежності — тільки з точною версією (`--save-exact`) і тільки ті, що вимагає завдання.

## Команди
- `npm run dev` — dev-сервер, http://localhost:3000 (слухає тільки 127.0.0.1)
- `npm run build` — продакшн-збірка (не запускати, поки працює `npm run dev`: обидва пишуть у `.next`)
- `npm run start` — запуск збірки, тільки 127.0.0.1:3000
- `npm run typecheck` — `tsc --noEmit`
- `npm test` — усі тести; `npx playwright test --project=node` / `--project=chromium` — окремо. Браузер для тестів: `npx playwright install chromium` (один раз). Сервер тестів запускається без ключа (`AISSTREAM_API_KEY=" "`).

## Правила
- Без тек і абстракцій «на майбутнє», без другої бібліотеки карт, без ESLint/Tailwind.
- `docs/` не видаляти й не переписувати без запиту.
- Production-код змінюється лише за завданням або підтвердженим розходженням; погоджені очікування тестів не послаблювати.
- Живі запити до AISStream — тільки з явного дозволу користувача; автотести їх не роблять. Справжні повідомлення в репозиторій не зберігати (зразок у `data/samples/` синтетичний).
- Узгоджена поведінка, а не дефекти: інтерфейс показує результат останньої спроби (на error/empty суден немає); `SubscriptionConfirmation` пропускається.
- Історично: обмеження спринту 1 («тільки карта й демо, без сервера/API, кнопки, справжніх даних») стосувались R1 і більше не діють.

## Секрети
- Не читати, не виводити й не комітити `.env*` та будь-які ключі доступу.
- `AISSTREAM_API_KEY` — тільки в `.env.local` (вносить людина), читається тільки на сервері; значення не потрапляє в чат, термінал, логи, відповіді й клієнтський код. Не обходити deny у `.claude/settings.json` shell-командами чи скриптами. Відстежується тільки `.env.example` без значення.
