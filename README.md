# Sea Radar

Навчальна програма для занять: карта Дуврської протоки з навчальними (демонстраційними) суднами, а за кнопкою — знімок справжніх суден на момент натискання із сервісу AISStream. Програма працює на вашому ноутбуці й відкривається тільки на ньому. Це навчальний посібник, не засіб для реальної навігації.

## Що потрібно
- **Node.js 24** (перевірка: `node -v` має показати `v24.…`). Разом із ним встановлюється `npm`.
- Сучасний браузер.
- **Інтернет** — для підкладки карти (OpenStreetMap) і для справжніх суден. Без інтернету навчальні судна й картки працюють, але карта під ними буде сірою.
- Ключ AISStream — тільки для справжніх суден. Без ключа навчальна частина працює повністю.

## Встановлення
1. Розпакуйте отриману теку проєкту й відкрийте в ній термінал.
2. Встановіть залежності (потрібен інтернет, кілька хвилин):
   ```
   npm ci
   ```

## Ключ AISStream (необов'язково)
Програма читає одну змінну — `AISSTREAM_API_KEY`. Її шаблон без значення лежить у файлі `.env.example`:
```
AISSTREAM_API_KEY=
```
1. Скопіюйте `.env.example` у тій самій теці під назвою `.env.local`.
2. Відкрийте `.env.local` у текстовому редакторі й впишіть ключ одразу після знака `=`, без пробілів і лапок.
3. Збережіть файл і (пере)запустіть програму.

Ключ отримують в обліковому записі на aisstream.io. Ключ читається тільки серверною частиною програми й у браузері не показується. **Не пересилайте `.env.local` і не показуйте його вміст на екрані**: цей файл не входить у комплект і не повинен потрапляти до інших людей. Щоб вимкнути справжні дані, видаліть рядок із ключем або сам файл і перезапустіть програму.

## Запуск на занятті
```
npm run build
npm run start
```
Відкрийте в браузері **http://localhost:3000**. Програма слухає тільки цей комп'ютер (адреса 127.0.0.1), з інших пристроїв вона недоступна. Зупинка — `Ctrl+C` у терміналі.

`npm run build` потрібен один раз після встановлення і після кожної зміни файлів програми. Для розробки замість цих двох команд є `npm run dev` (не запускайте `npm run build`, поки працює `npm run dev`).

## Що показує панель праворуч
Згори вниз:
1. **Кнопка** «Завантажити справжні позиції». Поки триває збір, вона заблокована.
2. **Підпис джерела** — що саме зараз на карті: «Демонстраційні дані» або «AISStream · знімок за 15 с · отримано HH:MM:SS UTC · суден: N · вибірка неповна» (якщо збір зупинився на ліміті — у кінці « · зупинено на ліміті 100»).
3. **Рядок останньої спроби** — з'являється після першого натискання: «Завантаження…» під час збору, далі результат спроби з її часом.
4. **Підказка** «Після оновлення сторінки знову показуються демонстраційні дані».
5. **Картка** обраного судна.

**Правило збереження набору.** На карті лишається останній показаний набір — навчальні судна або останній вдалий знімок. Під час збору, після помилки й після порожнього результату він не змінюється, підпис джерела теж; змінюється тільки рядок останньої спроби. Набір замінює лише непорожній знімок справжніх суден. Підпис джерела завжди описує саме показані дані, тож старий знімок не видається за свіжий. Після оновлення сторінки (F5) на карті знову навчальні судна.

Усі часи в підписі й рядку спроби — час сервера (UTC), а не годинник браузера.

## Як перевірити, що все працює
1. **Навчальна частина.** На сторінці — карта протоки (Дувр — Кале), праворуч кнопка, підпис «Демонстраційні дані» і підказка; рядка спроби ще немає. Три навчальні судна рухаються раз на 2 секунди, значки повернуті в бік руху. Клік по судну відкриває картку: ідентифікатор, назва, координати, швидкість, курс, час, джерело. Приблизно за 20 секунд усі три судна доходять до кінця маршруту й зупиняються (швидкість `0 kn`). Після оновлення сторінки рух починається спочатку.
2. **Без ключа.** Натисніть «Завантажити справжні позиції». Навчальні судна лишаються на карті й продовжують рух, підпис — «Демонстраційні дані», а в рядку спроби — «Спроба HH:MM:SS UTC: не вдалося отримати дані: Ключ AISStream не налаштовано». Це очікувана поведінка, не збій.
3. **З ключем.** Натисніть кнопку: близько 15 секунд у рядку спроби «Завантаження…», а на карті все, що було (навчальні судна рухаються).
   - Вдалий знімок: на карті справжні судна (між завантаженнями вони не рухаються), підпис «AISStream · знімок за 15 с · отримано HH:MM:SS UTC · суден: N · вибірка неповна», рядок «Спроба HH:MM:SS UTC: отримано суден: N». Навчальні судна зникають до оновлення сторінки.
   - За 15 секунд позицій не прийшло: карта й підпис без змін, рядок «Спроба HH:MM:SS UTC: за час збору позицій не отримано».
   - Джерело недоступне: карта й підпис без змін, у рядку спроби — причина (таблиця нижче).
   - Повторне натискання після вдалого знімка: до нового вдалого результату на карті лишається попередній знімок зі своїм часом у підписі.
4. **Автоматичні перевірки** (за бажанням; потрібен інтернет для першого кроку):
   ```
   npx playwright install chromium
   npm test
   ```
   Усі тести мають пройти (`passed`, жодного `failed`). Тести не звертаються до AISStream і ключа не потребують. Що саме вони доводять — `docs/reviews/ACCEPTANCE-R3.md` (дані й рух) і `tests/b19-r4.spec.ts` (правило збереження набору).

## Що програма вміє
- Показати карту протоки з початковим видом; карту можна пересувати й масштабувати. При першому вдалому знімку карта повертається до початкового виду, далі вид не змінюється.
- Показати три навчальні судна, що рухаються заданими маршрутами й зупиняються в кінці.
- Відкрити картку судна кліком; картка не закривається повторним кліком чи кліком по карті й оновлюється разом із рухом судна. Невідоме значення — «Немає даних», а не нуль; нульова швидкість — `0 kn`. Якщо обране судно є в новому знімку — картка показує його нові дані; якщо немає — закривається.
- За кнопкою зібрати знімок справжніх позицій у протоці на момент натискання: до 15 секунд і не більше 100 суден; для кожного судна — найсвіжіше повідомлення.
- Завжди підписувати, що на карті: навчальні судна чи справжні, коли отримані, скільки, і що вибірка неповна.
- Окремим рядком показувати результат останньої спроби з її часом і пояснювати невдачу зрозумілою фразою, не прибираючи з карти показаний набір.

## Чого програма не вміє (і не повинна)
- Безперервного чи автоматичного оновлення: справжні судна — знімок на момент натискання, між завантаженнями вони не рухаються.
- Показати повну картину протоки: вибірка неповна; скільки суден прийде, залежить від безкоштовного джерела й часу доби. Якщо судна немає в новому знімку, це не означає, що воно вийшло з району.
- Зберігати знімок між оновленнями сторінки: після оновлення знову навчальні судна.
- Повернути навчальні судна після вдалого знімка без оновлення сторінки.
- Поєднувати, порівнювати знімки чи вести їхню історію; позначати судна, яких немає в новому знімку.
- Історії руху, слідів, зон і тривог, пошуку й фільтрів, кількох районів, збереження налаштувань, входу за паролем, роботи з інших комп'ютерів чи з сервера в інтернеті.
- Працювати з картою без інтернету.
- Слугувати для реальної навігації.

## Повідомлення про невдачу
У всіх випадках карта й підпис джерела лишаються як були; змінюється тільки рядок спроби.

| Рядок спроби «… не вдалося отримати дані: …» | Що означає |
|---|---|
| Ключ AISStream не налаштовано | немає `.env.local` або ключа в ньому; навчальна частина працює |
| Не вдалося підключитися до джерела | немає інтернету або сервіс не відповів за 15 секунд |
| Джерело повернуло помилку | сервіс надіслав повідомлення про помилку або незрозумілі дані; перевірте ключ і спробуйте ще раз |
| З'єднання з джерелом розірвано | з'єднання обірвалося під час збору; перевірте ключ і інтернет і спробуйте ще раз |
| Внутрішня помилка сервера | непередбачена помилка програми; перезапустіть її |
| Немає відповіді сервера (рядок без часу: «Спроба: не вдалося отримати дані: Немає відповіді сервера») | програма-сервер не відповіла або відповіла незрозуміло — найчастіше її зупинено в терміналі; запустіть її знову |

## Якщо щось не так
- **`npm ci` або запуск скаржиться на версію Node** — встановіть Node.js 24.
- **Порт 3000 зайнятий** (`EADDRINUSE`) — програма вже запущена в іншому терміналі; закрийте її або скористайтеся вже відкритою.
- **Сіра карта** — немає інтернету або сервер карт недоступний; навчальні судна й картки при цьому працюють.
- **Справжніх суден мало або «за час збору позицій не отримано»** — так буває з безкоштовним джерелом; спробуйте пізніше.
