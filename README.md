# Sea Radar

Навчальна програма для занять: карта Дуврської протоки з навчальними (демонстраційними) суднами, а за кнопкою — короткий знімок справжніх суден із сервісу AISStream. Програма працює на вашому ноутбуці й відкривається тільки на ньому. Це навчальний посібник, не засіб для реальної навігації.

## Що потрібно
- **Node.js 24** (перевірка: `node -v` має показати `v24.…`). Разом із ним встановлюється `npm`.
- Сучасний браузер.
- **Інтернет** — для підкладки карти (OpenStreetMap) і для справжніх суден. Без інтернету навчальні судна й картки працюють, але карта під ними буде сірою.
- Ключ AISStream — тільки для справжніх суден. Без ключа навчальна частина працює повністю.

## Встановлення
1. Розпакуйте отриману теку проєкту й відкрийте в ній термінал.
2. Встановіть залежності (потрібен інтернет, кілька хвилин):
   ```
   npm ci
   ```

## Ключ AISStream (необов'язково)
1. Скопіюйте файл `.env.example` у тій самій теці під назвою `.env.local`.
2. Відкрийте `.env.local` у текстовому редакторі й впишіть ключ одразу після знака `=`, без пробілів і лапок:
   ```
   AISSTREAM_API_KEY=ваш_ключ
   ```
3. Збережіть файл і (пере)запустіть програму.

Ключ отримують в обліковому записі на aisstream.io. Ключ читається тільки серверною частиною програми й у браузері не показується. **Не пересилайте `.env.local` і не показуйте його вміст на екрані**: цей файл не входить у комплект і не повинен потрапляти до інших людей. Щоб вимкнути справжні дані, видаліть рядок із ключем або сам файл і перезапустіть програму.

## Запуск на занятті
```
npm run build
npm run start
```
Відкрийте в браузері **http://localhost:3000**. Програма слухає тільки цей комп'ютер (адреса 127.0.0.1), з інших пристроїв вона недоступна. Зупинка — `Ctrl+C` у терміналі.

`npm run build` потрібен один раз після встановлення і після кожної зміни файлів програми. Для розробки замість цих двох команд є `npm run dev` (не запускайте `npm run build`, поки працює `npm run dev`).

## Як перевірити, що все працює
1. **Навчальна частина.** На сторінці — карта протоки (Дувр — Кале), праворуч підпис «Демонстраційні дані» і кнопка. Три навчальні судна рухаються раз на 2 секунди, значки повернуті в бік руху. Клік по судну відкриває картку: ідентифікатор, назва, координати, швидкість, курс, час, джерело. Приблизно за 20 секунд усі три судна доходять до кінця маршруту й зупиняються (швидкість `0 kn`). Після оновлення сторінки рух починається спочатку.
2. **Без ключа.** Натисніть «Завантажити справжні позиції». Має з'явитися «Не вдалося отримати дані: Ключ AISStream не налаштовано» і підпис «Даних на карті немає». Це очікувана поведінка, не збій. Навчальні судна повертаються після оновлення сторінки.
3. **З ключем.** Натисніть кнопку: близько 15 секунд підпис «Завантаження…», потім підпис на кшталт «AISStream · знімок за 15 с · отримано 09:08:07 UTC · суден: N · вибірка неповна» і справжні судна на карті. Якщо за 15 секунд позицій не прийшло — «суден: 0» і «За час збору позицій не отримано»; якщо джерело недоступне — повідомлення про причину (таблиця нижче).
4. **Автоматичні перевірки** (за бажанням; потрібен інтернет для першого кроку):
   ```
   npx playwright install chromium
   npm test
   ```
   Усі тести мають пройти (`passed`, жодного `failed`). Тести не звертаються до AISStream і ключа не потребують. Що саме вони доводять — `docs/reviews/ACCEPTANCE-R3.md`.

## Що програма вміє
- Показати карту протоки з початковим видом; карту можна пересувати й масштабувати.
- Показати три навчальні судна, що рухаються заданими маршрутами й зупиняються в кінці.
- Відкрити картку судна кліком; картка не закривається повторним кліком чи кліком по карті й оновлюється разом із рухом судна. Невідоме значення — «Немає даних», а не нуль; нульова швидкість — `0 kn`.
- За кнопкою зібрати знімок справжніх позицій у протоці: до 15 секунд і не більше 100 суден; для кожного судна — найсвіжіше повідомлення.
- Завжди підписувати, що на карті: навчальні судна чи справжні, коли отримані, скільки, і що це не всі судна району.
- Пояснювати невдачу зрозумілою фразою.

## Чого програма не вміє (і не повинна)
- Безперервного оновлення: справжні судна — знімок на момент натискання, між завантаженнями вони не рухаються.
- Показати всі судна району: знімок — неповна вибірка; скільки суден прийде, залежить від безкоштовного джерела й часу доби.
- Зберігати попередній знімок: на карті завжди результат останньої спроби; після помилки чи порожнього збору суден на карті немає.
- Повернути навчальні судна без оновлення сторінки.
- Історії руху, слідів, зон і тривог, пошуку й фільтрів, кількох районів, збереження налаштувань, входу за паролем, роботи з інших комп'ютерів чи з сервера в інтернеті.
- Працювати з картою без інтернету.
- Слугувати для реальної навігації.

## Повідомлення про невдачу
| Повідомлення «Не вдалося отримати дані: …» | Що означає |
|---|---|
| Ключ AISStream не налаштовано | немає `.env.local` або ключа в ньому; навчальна частина працює |
| Не вдалося підключитися до джерела | немає інтернету або сервіс не відповів за 15 секунд |
| Джерело повернуло помилку | сервіс надіслав повідомлення про помилку або незрозумілі дані; перевірте ключ і спробуйте ще раз |
| З'єднання з джерелом розірвано | з'єднання обірвалося під час збору; перевірте ключ і інтернет і спробуйте ще раз |
| Внутрішня помилка сервера | непередбачена помилка програми; перезапустіть її |

## Якщо щось не так
- **`npm ci` або запуск скаржиться на версію Node** — встановіть Node.js 24.
- **Порт 3000 зайнятий** (`EADDRINUSE`) — програма вже запущена в іншому терміналі; закрийте її або скористайтеся вже відкритою.
- **Сіра карта** — немає інтернету або сервер карт недоступний; навчальні судна й картки при цьому працюють.
- **Справжніх суден мало або «суден: 0»** — так буває з безкоштовним джерелом; спробуйте пізніше.
