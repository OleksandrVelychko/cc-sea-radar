## Зроблено
- B-01: каркас Next.js 16.4.2 (App Router) + React 19.3.1 + TypeScript 6.0.3 (`strict`), зібраний вручну без create-next-app; `package-lock.json`, `.gitignore`, `CLAUDE.md`, `docs/checkpoints/TEMPLATE.md`.
- `AGENTS.md` — не написаний вручну: його створює й відновлює `next dev`, коли виявляє ШІ-агента (`node_modules/next/dist/server/lib/generate-agent-files.js`). Призначення — стандартний блок Next.js з вимогою звіряти код з документацією встановленої версії (`node_modules/next/dist/docs/`). Комітимо як є; `CLAUDE.md` підключає його через `@AGENTS.md`.
- B-02: Leaflet 1.9.4 (+ `@types/leaflet` 1.9.22) завантажується тільки в браузері (`import("leaflet")` у `useEffect` клієнтського компонента `app/SeaMap.tsx`); шар OSM Standard з атрибуцією; район, початковий вид і шар — в `app/config.ts`; карта на все вікно; `ResizeObserver` → `invalidateSize()`; при демонтуванні `map.remove()`.
- B-03: тип `Vessel` за полями SPRINT-01 (`app/vessel.ts`); одне нерухоме судно `demo-1` «Демо-судно 1» (51.02000, 1.38000; 12.3 kn; 45°) — літерали в `app/config.ts`, `timestamp` — момент створення в браузері; значок `divIcon` із DOM-елемента: стрілка, повернута на `courseDeg`, або круг при `null`; атрибути `data-vessel-id`, `data-icon="course"|"neutral"`; підпис «Демонстраційні дані» на панелі праворуч.
- B-04: стан суден і `selectedId` в одному місці (`app/Radar.tsx`), карта й картка читають звідти; клік по значку обирає судно, повторний клік і клік по карті вибір не змінюють, кнопки закриття немає; картка (`app/VesselCard.tsx`) за форматами SPRINT-01, усі значення — текстові вузли React.
